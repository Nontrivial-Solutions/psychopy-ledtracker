## Goals

The usecase models the resetting of a LED array device into a known usable state.

### Happy Outcome

When the usecase completes successfully the underlying LED device is set to a usable state and is
released for reuse.

### Sad Outcome

When the usecase completes unsuccessfully a failure is handled.

## Preconditions

- A LED device is physically connected.
- A LED device is set up.

## Actors

- [Time](../actors/00002_time.md)

## Trigger

The LED device is no longer needed and can be set to a usable state then released.  

## Scenario

1. The LED array is connected  
1. The LED array set to a usable state
1. The LED array device lock is released
1. An error occurs:
    1. Set error state
