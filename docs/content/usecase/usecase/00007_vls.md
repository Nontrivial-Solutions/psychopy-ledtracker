## Goals

The usecase models the validation of the state of the LED array.  

### Happy Outcome

When the use case completes successfully the LED array state is validated.

### Sad Outcome

When the use case completes unsuccessfully a failure is handled.

## Preconditions

- A LED array device is physically connected.

## Actors

None

## Trigger

An upstream time actor triggers the validation of the LED array state.

## Scenario

1. The LED array is connected
1. A LED array device state is requested
1. The LED array state is compared to the expected state
1. An error occurs:
    1. Set error state
