## Goals

This usecase models commanding the LED array to turn off a specific LED.  

### Happy Outcome

When the usecase completes successfully the desired LED array is set to the off state.

#### Sad Outcome

When the usecase completes unsuccessfully a failure is handled.

### Preconditions

- A LED array device is physically connected.
- The LED count is set.

### Actors

None

### Trigger

The time actor triggers the setting of a LED based on experiment polling.

### Scenario

1. The LED array is connected
1. A LED array state is set for an LED
1. An error occurs
    1. Set error state
