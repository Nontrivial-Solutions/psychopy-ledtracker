## Goals

The usecase models the connecting and setting of a LED array device into a known usable state.

### Happy Outcome

When the usecase completes successfully the underlying LED device is set connected and set to a
usable state.

#### Sad Outcome

When the usecase completes unsuccessfully a failure is handled.

### Preconditions

- A LED device is physically connected.

### Actors

- [Time](../actors/00002_time.md)

### Trigger

The LED device is needed and must be connected, set to a usable state, and locked.  

### Scenario

1. The LED array device lock is acquired
1. The LED array is connected  
1. The LED array set to a usable state
1. An error occurs:
    1. Set error state
