## Goals

This usecase models commanding the LED array to enter a specific state.

### Happy Outcome

When the usecase completes successfully the LED array is in the desired state.

#### Sad Outcome

When the usecase completes unsuccessfully a failure is handled.

### Preconditions

- A LED array device is physically connected.

### Actors

None

### Trigger

An upstream actor triggers a usecase which sets LED state.

### Scenario

1. The LED array is connected
1. A serial LED array is sent a serial command
1. The LED array state is verified
1. An error occurs:
    1. Set error state
