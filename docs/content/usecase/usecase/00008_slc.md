## Goals

This usecase models setting the count of LEDs in the LED array  

### Happy Outcome

When the usecase completes successfully the desired LED array count is set.

#### Sad Outcome

When the usecase completes unsuccessfully a failure is handled.

### Preconditions

- A LED array device is physically connected.

### Actors

None

### Trigger

An upstream time actor triggers the setting of an LED count.

### Scenario

1. The LED array is connected
1. A LED array count is set to the device
1. An error occurs
    1. Set error state
